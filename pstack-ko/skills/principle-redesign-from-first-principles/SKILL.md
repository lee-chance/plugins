# Redesign From First Principles (First Principles로부터 재설계)

변경을 통합할 때, 기존 설계에 볼트로 고정하지 마세요. 요구사항이 시작부터 기본 가정이었던 것처럼 재설계하세요.

- 영향을 받는 모든 파일을 읽고 현재 설계를 이해하세요
- 질문하세요: "이 새 요구사항으로 처음부터 작성한다면, 무엇을 빌드할 것인가?"
- 모든 참조를 통해 변경을 전파하세요: 타입, 문서, 예제, 근거 섹션
- 전체 재설계를 생각한 다음, 점진적으로 전달하세요

이것은 기존 설계에 변경을 통합할 때 옵션 가치를 보존하는 방법입니다.
